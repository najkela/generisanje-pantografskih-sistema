## Дискусија

Ноћни задатак: имплементација bilevel метода (спољашњи ГА над топологијом + унутрашњи
ЦМА-ЕС над геометријом), по одлукама донетим у чет-сесији 04.09. увече (пре ове сесије).
Рад иде по целинама А→Ж из `PROMPT_BILEVEL.md`, комит по целини на грани `bilevel`,
pytest после сваке. Овај фајл (`docs/IZVESTAJ_NOC.md`) носи детаљан ток; овде је сажетак
за дневник.

## Одлуке

Одлуке А1–А7 из `PROMPT_BILEVEL.md` уписане у `docs/DECISIONS.md` §22 пре кодирања:

- **ОДЛУКА — параметризација вектора геометрије:** база `(q1, q2, ρ_a, ρ_b, ...)` изведена
  из секвенце склапања, не сирове координате свих чворова. Знак гране `s` је дискретан ген
  топологије (§17 закуцана грана), не последица положаја у претрази.
- **ОДЛУКА — мртви чворови не заузимају димензије ЦМА-ЕС вектора.**
- **ОДЛУКА — спољашњи ниво носи живо ЦМА-ЕС стање по топологији кроз генерације** (нема
  рестарта елите).
- **ОДЛУКА — warm-start = наслеђена средина + сопствена почетна σ за нове димензије**
  (дијагонала, не пуна коваријанса).
- **ОДЛУКА — један кандидат = један позив буџета**, укључујући промашаје на реконструкцији.
- **ОДЛУКА — невалидна тополошка мутација кошта један позив, не цео ЦМА-ЕС ран.**
- **ОДЛУКА — у bilevel-у нема координатне мутације ни укрштања** (H2 default, само-мутација).

Ово затвара отворено питање 2.1 у целости (`docs/OPEN_QUESTIONS.md`).
