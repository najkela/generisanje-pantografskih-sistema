# Извештај — ноћна bilevel сесија (05.09.)

> Ажурира се после сваке целине из `PROMPT_BILEVEL.md`, не тек на крају. Ако нешто заустави
> рад јер противречи закљученој одлуци, тај случај иде НА ВРХ овог фајла.

## ⚠️ НАЈВАЖНИЈЕ ЗА ЈУТРО — нађено у целини Ж, не у А–Ђ

Имплементација (А–Ђ) је прошла све тестове и регресију бит-идентично. Али мерење H1 на
ПУНОМ профилу (динамички N) је откуцало методолошки проблем, не резултат метода: **свих 18
bilevel покретања главне матрице остало је заглављено на N=90 од почетка до краја буџета**
— плато-прозори за раст резолуције/заустављање (`plateau_window_grow=15`,
`plateau_window_stop=30`) су бројани по ГЕНЕРАЦИЈИ, а bilevel-ова генерација кошта ред
величине више позива (K×λ по топологији) него baseline-ова, па bilevel стигне до свега
16–20 генерација укупно пре него што буџет пресуши — никад не достигне ни један прозор.
Последица: `final_error` за bilevel у главној матрици је на N=90, за baseline на N=720 —
Chamfer на различитим N НИЈЕ упоредив (DECISIONS §17). **Наивно поређење медијана из
главне матрице би било грешка, не налаз.**

Пун опис, узрок и додатна дијагностика (фиксно N=720 за оба метода, seed 1): в.
`docs/NALAZ_05_09_bilevel.md`. Ново отворено питање уписано:
`docs/OPEN_QUESTIONS.md` §6.6 — **не решавано самоиницијативно**, чека Николину одлуку
(посебни прозори по методу? мерење по позивима уместо по генерацији? нешто треће?).

## Одлуке које чекају потврду

- **DECISIONS §23 — читање H1 налаза од 05.09.** Главна матрица методолошки неисправна
  (§6.6), дијагностика на фиксном N охрабрујућа али на једном seed-у. Предлог: не
  сматрати H1 ни потврђеним ни оборeним, решити §6.6 па поновити главну матрицу.
- **`bilevel._construct_cma_es` clip-ује почетну тачку (`x0`) ЦМА-ЕС-а у
  `[cma_rho_lower, cma_rho_upper]` (в. целина Ђ).** Нађено емпиријски (тест 4), промпт то
  не помиње. Алтернатива која НИЈЕ примењена: третирати такво дете као невалидно (казна,
  без ЦМА-ЕС-а) уместо clip-а — то би бацило геометрију коју су оператори већ легитимно
  произвели само зато што један `ρ` благо прелази границу намењену ПРЕТРАЗИ, не старту.
  Clip делује као мања интервенција, али мења семантику границе (сад важи и на старту).
  Тражи преглед пре него што уђе у мерење као трајно решење.
