## 1. Проблем

Дат је уређен скуп тачака у 2Д равни. Циљна крива је **затворена изломљена линија**
добијена спајањем тачака редом (тачка i → i+1, последња → прва). Циљ: пронаћи пантографски
механизам чији **tracer чвор**, при пуној ротацији crank-а, описује путању која што ближе
прати циљну криву.

**Формат уноса (тренутно):** фајл са 720 тачака, свака у засебном реду, координате одвојене
зарезом.
**Формат уноса (каснији update):** GUI где корисник нацрта криву, програм извуче 720 тачака,
па downsample да се N поклопи.

## 2. Механизам и геном

**Комплетан опис механизма** = топологија (чворови, ивице, улоге) + геометрија (почетне
координате чворова, из којих се рачунају дужине кракова).

**Конвенција индекса (закључано):**

- индекси 0, 1 = fixed чворови
- индекс 2 = crank
- индекс n−1 = tracer
- обавезна ивица (0, 2)
- crank (2) везан искључиво за fixed чвор 0, никад за fixed чвор 1

**Две структуре генома** (оба метода описују ИСТИ простор решења):

Baseline (чист ГА) — монолитни геном:

```
genome_GA = { "n_nodes": int, "edges": [(i,j),...], "coords": {node: [x,y],...} }
```

Bilevel — раздвојено:

```
genome_topology = { "n_nodes": int, "edges": [(i,j),...] }   # спољашњи ГА, без координата
x = [x_1, y_1, ..., x_{n-1}, y_{n-1}]                        # унутрашњи ЦМА-ЕС, раван вектор
```

Мапирање вектор↔чворови мора бити детерминистичко и фиксно.

## 3. Геометријске конвенције и димензионалност

- fixed чвор 0 закуцан у (0,0) — уклања само транслацију.
- fixed чвор 1 потпуно слободан — контролише ротацију и скалирање целог механизма; ниједна
  координата се не фиксира.
- димензионалност континуалног вектора = **2·n_nodes − 2**, идентично за оба метода.
- механизам мора имати **DOF = 1** (Grübler–Kutzbach: DOF = 3(n−1) − 2j). Провера
  „тачно 2 позната суседа при решавању" имплицитно обезбеђује DOF=1.

## 4. Валидација топологије + solving order

Редослед провера (јефтине прво):

1. Структурне провере — без self-loop, без дуплираних ивица, без изолованих чворова.
2. Провера степена — тачно 2 fixed, тачно 1 crank, сваки floating чвор укупан степен
   **бар 2** (≥2, НЕ тачно 2 — да чвор може бити родитељ другом чвору → дубоки механизми).
3. Провера ослонца crank-а — тачно једна ивица crank→fixed.
4. Конструкција solving order-а (BFS): `known = {2 fixed} ∪ {crank}`; понављај — нађи
   floating чвор са **тачно 2 позната суседа**, реши га (circle-circle intersection),
   премести у known; ако пролаз не направи напредак → невалидно (циклична зависност).

Напомена: „бар 2" је услов укупног степена (нужан); „тачно 2 позната суседа" се проверава
у тренутку решавања унутар BFS-a (то је стварни услов решивости). Ова разлика је важна —
исправка од 07.08.

## 5. Фитнес функција — Chamfer дистанца

```
d(G,T) = (1/n) Σ_i min_j ||g_i - t_j||²  +  (1/m) Σ_j min_i ||t_j - g_i||²
```

- Симетрична (оба смера) — спречава дегенерисана решења.
- Инваријантна на смер и брзину обиласка (смер није битан за циљ пројекта).
- Убрзање: `scipy.spatial.cKDTree` над циљном кривом (грађен једном), O(n log m).
- Невалидне геометрије/топологије → велика КОНАЧНА казна (не бесконачност — ради ЦМА-ЕС
  стабилности).

## 7. Главна хипотеза (H1) и структура рада

**H1 (примарна, једина носећа):** Раздвајање претраге на bilevel структуру (ГА-топологија +
ЦМА-ЕС-геометрија) даје ниже коначне грешке и/или бржу конвергенцију од истовремене
оптимизације целог генома (чист ГА), при истом буџету евалуација, јер унутрашњи ЦМА-ЕС
експлицитно моделује спрегу континуалних параметара коју истовремени приступ третира као
независне.

**Теоријски извор:** Ong, Shirakawa & Akimoto (2026), *Mixed-Categorical Black-Box
Optimization via Information-Geometric Bilevel Decomposition* — методи који мешовите
categorical-continuous просторе третирају заједно губе перформансе кад постоје јаке
интеракције међу варијаблама.

**H2 и H3 нису независна истраживања** — демотиране у мотивисане имплементационе одлуке
унутар главног експеримента:

- H2: crossover vs. само-мутација топологије (default: само-мутација).
- H3: јачина спреге ГА↔ЦМА-ЕС, фиксни K vs. динамички K (default: динамички K).

## 8. Предмет поређења и метрике

- **Baseline:** чист ГА над целим геномом (истовремени приступ, ≈ оригинална замисао из
  првог предлога). Мора бити best-effort, не намерно ослабљен.
- **Наш метод:** bilevel (ГА-топологија + ЦМА-ЕС-геометрија + warm-start).
- **Метрике:** (1) коначна Chamfer грешка при истом буџету; (2) брзина конвергенције као
  функција **броја позива симулатора** (фер јединица трошка); (3) конзистентност
  (варијанса преко више seed-ова).
- **Буџет:** бројање на нивоу позива симулатора (једна bilevel евалуација топологије троши
  K позива унутра; једна baseline јединка троши 1). Почетно макс 150, мења се у ходу.

## 9. Механизам оптимизације — детаљи

- **Мутациони оператори (само-мутација):** додај чвор (нови floating, везан за 2 постојећа,
  warm-start позиција интерполацијом), обриши чвор, додај ивицу, обриши ивицу. Улоге
  (fixed/crank/tracer) се НИКАД не мењају мутацијом.
- **Невалидне мутације:** јединка остаје у популацији уз велику коначну казну; мутација се
  НЕ понавља до валидног генома.
- **Warm-start:** ГА при мутацији наслеђује/интерполира геометрију родитеља као почетну
  средину ЦМА-ЕС расподеле, уместо насумичне иницијализације.
- **Динамички N (резолуција криве):** плато-детекција (клизни прозор W, праг ε) — расте
  90→720 кроз генерације; кад је N=720 и плато траје, служи и као критеријум заустављања.
- **Динамички K (спрега):** плато-детекција унутар ЦМА-ЕС рана (early stopping).
  Референтне фиксне вредности за поређење: 5/15/40.

## 10. Позиционирање према литератури (три фамилије)

1. Истовремена оптимизација (baseline).
2. Bilevel (наш метод).
3. Data-driven retrieval (McGarva 1994; LInK 2024) — НЕ имплементиран као baseline
   (различита природа трошка, нема фер заједничке јединице); помиње се само као контекст
   у literature review-у, објашњава зашто рад бира оптимизациони пут.

## 11. Тест криве (три нивоа)

- Ниво 1 — аналитичке (круг, елипса): валидација исправности pipeline-а.

## 14. Baseline координатна мутација (закључано 09.08.)

Затвара отворено питање 1.1 и деблокира имплементацију baseline-а.

- **Спрега:** независна — свака новоукрштена јединка независно „баца новчић" за тополошку
  мутацију (p_topo) и за координатну мутацију (p_coord); могу се десити обе, једна или
  ниједна.
- **Механизам:** per-node изотропни Гаусов шум — сваки чвор осим чвора 0 (закуцан у (0,0))

  јединке у тренутку мутације), не фиксна апсолутна вредност — апсолутна вредност би била
  бесмислена јер координате нису нормализоване (нормализује се само циљна крива).
- **Распоред:** коефицијент k опада кроз генерације (веће мутације рано, финије касно).

## 15. Секвенца склапања, укрштање и оператори (закључано 30.08.)

Извршни облик свих одлука из ове секције: `docs/BASELINE_SPEC.md`. Формално образложење: README 1.2.1, 1.4, 2.2, 2.3, 4.1–4.3.

**ОДЛУКА — DOF формула:** `DOF = 2(n−2) − j`, дакле `j = 2n − 5`. Ранија Grübler–Kutzbach формула `3(n−1) − 2j` је погрешна за наш начин бројања (n = зглобови, j = полуге) и важила је случајно само за n = 6.

**ОДЛУКА — ивица (0,1) не постоји:** чворови 0 и 1 су оба закуцана за подлогу; веза међу њима је подлога, не полуга, и не улази ни у `E` ни у `j`. Најмањи валидан механизам (n = 4) има три ивице.

**ОДЛУКА — секвенца склапања као канонски облик:** уведен изведени запис `S = [0,1,2,u_3,...,u_{n-1}]` са геном корака `(a_k, b_k, ρ_a, ρ_b, s_k)`. Односи важе искључиво у θ = 0; дужине се фиксирају једном при реконструкцији и симулација их не мења.

**ОДЛУКА — детерминистички tie-break у BFS-у:** при више кандидата бира се најмањи индекс чвора. Без овога канонизација није једнозначна и репродуцибилност пада. → **ПОВУЧЕНО 31.08., в. секцију 16.**

**ОДЛУКА — tracer је последњи у секвенци:** додата пета провера валидације. Ниједан чвор не сме висити на tracer-у.

**ОДЛУКА — улоге се изводе из позиције:** fixed = позиције 0 и 1, crank = позиција 2, tracer = последња позиција. Ово мења одлуку од 16.07. („улоге се никад не мењају мутацијом") — fixed и crank остају непроменљиви, али tracer прати крај секвенце. Без тога је `add_node` мртав потез.

**ОДЛУКА — укрштање је рез секвенце склапања:** дете = језгро од A + гени `g_3..g_{c-1}` од A + гени `g_c..g_{n_B-1}` од B. Дете је структурно валидно по конструкцији; пада само на circuit defect, без поправке.

**ОДЛУКА — два оператора, оба над чворовима:** ивични оператори (`add_edge`, `delete_edge`) укинути. `add_node` има два начина (А: допиши на крај, обавезан ослонац на дотадашњем tracer-у; Б: убаци пре tracer-a, неутрална мутација која омогућава рачвање). `delete_node` преспаја зависнике насумичним избором из ослонаца обрисаног чвора; чвор задржава позицију у θ = 0.

**ОДЛУКА — мртав терет се не креше током претраге:** чворови ван предачког стабла tracer-a остају у геному као материјал за касније потезе. Симулатор за фитнес решава само претке tracer-a. `prune_dead_nodes()` се позива само над коначним резултатом.

**ОДЛУКА — буџет:** укупно 50 000 позива симулатора по покретању, идентично за оба метода. Раније навођених „150" је горња граница за K (ЦМА-ЕС итерације по процени једне топологије), не укупан буџет.

**ОДЛУКА — четири RNG тока:** `rng_init`, `rng_select`, `rng_cross`, `rng_mut`, изведени из једног главног seed-а преко `SeedSequence.spawn`.

**ОДЛУКА — одсецање валидног фитнеса на 1e8, казна 1e9:** без одсецања валидна јединка може бити оцењена горе од невалидне.

## 16. Инваријанта редоследа замењује BFS (закључано 31.08.)

**ОДЛУКА — инваријанта редоследа:** за сваки чвор `k ≥ 3` важи да скуп његових суседа мањег индекса има **тачно два** елемента. То су ослонци чвора `k`.

**ОДЛУКА — валидација проверава инваријанту, не тражи редослед:** BFS претрага се укида. Solving order је увек `[3, 4, …, n−1]`, једнак редоследу индекса, па се не мора рачунати; ослонци чвора се читају као `sorted(m for m in neighbors(k) if m < k)`.

**ОДЛУКА — tie-break се повлачи:** одлука од 30.08. („при више кандидата бира се најмањи индекс чвора") постојала је само зато што BFS може имати више решења. Уз инваријанту избора нема, па је правило беспредметно и брише се. Канонизација је једнозначна сама по себи.

**ОДЛУКА — обавеза оператора:** сваки оператор, постојећи и будући, мора одржати инваријанту. Проверено да је одржавају: `random_initial_genome` и `from_sequence` (граде чворове редом, ослонци увек `< k`), `add_node` начин А (ослонци стари tracer и још један, оба `< n`), начин Б (ослонци из `range(old_tracer)`, стари tracer се помера на `n`), `delete_node` (`r ∈ {a_u, b_u}`, оба решена пре `u`, дакле пре сваког зависника).

**ОБРАЗЛОЖЕЊЕ ЗАДРЖАВАЊА ПРОВЕРЕ:** иако за геном произведен операторима провера не може да падне, `Topology` је обичан скуп ивица и склапа се и ручно — у тестовима, у `run.py demo`, сутра у `bilevel.py`. Провера више не тражи одговор него потврђује да оператори одржавају оно што су дужни. Оператор са грешком у преспајању овде пада; тривијално враћен редослед `[3, …, n−1]` не би.

**ПОРЕКЛО:** запажање Николе — ако се геном ионако гради чвор по чвор, редослед је већ садржан у самом запису и не мора да се тражи.

## 17. Поза, грана пресека и буџет (закључано 02.09.)

Извориште: `docs/NALAZ_01_09_poza.md` (мерења од 01.09. увече). Свака одлука је прошла кроз
приговор и мерење, не кроз процену.

**ОДЛУКА — закуцана грана circle-circle пресека.** `simulator.positions_at` више не бира
грану по близини претходног положаја. За сваки чвор се једном, у θ=0, рачуна знак гране

тај знак важи на сваком углу. `_closer_branch` се уклања са вруће путање.

Образложење: грана је својство склопа, не историје. Прелазак на другу грану захтева пролаз
кроз мртву тачку (`h = 0`, угао преноса 0°), коју праг угла преноса већ одбија. Прескок
постаје структурно немогућ, а конфигурација на углу θ зависи само од θ и вектора знакова.
Механизам који на својој грани нема решење се закочи → `None` → казна.

Мерено: не одбацује здраве јединке (310/397 тополошки валидних заврши пун обртај — исти
број са хеуристиком и са закуцаном граном). Успутна последица: Chamfer постаје монотона
функција од N и конвергира; са хеуристиком је скакао (за једну јединку 7.3e-02 → 8.3e-02 →
3.9e-02 → 2.3e-02 → 3.8e-02 за N = 90/180/360/720/2880, са минимумом баш на пријављеном
N=720, док иста јединка са закуцаном граном даје монотоно 4.1e-02 → … → 3.8e-02).

**Затвара отворено питање 4.1 (circuit defect)** — укидањем узрока, не увођењем провере.
Провера затварања конфигурације (сви чворови на θ=2π наспрам θ=0) остаје као тест-асертација:
као детектор није поуздана јер хвата само непаран број промена гране.

**ОДЛУКА — пуна скална инваријантност фитнеса.** Генерисана путања се пре Chamfer-a
нормализује истом функцијом као циљна крива (`curve.normalize`). Фитнес мери искључиво облик.
Геном се током претраге не дира — чвор 0 остаје закуцан у (0,0), димензионалност остаје
`2n−2`. На крају покретања најбоља сличносна трансформација се примењује на координате
најбољег генома, па снимљени механизам стварно исцртава циљну криву на њеном месту и у
њеној величини (сличносна трансформација координата даје идентично трансформисану путању —
провера, одступање 1.3e-15).

Мерено (елипса, буџет 12 000, популација 50, заједничка мера = Chamfer после оптималне
сличносне трансформације): без инваријантности 2.02e-02, само транслациона 4.65e-04 (43×),
транслација+скала 1.26e-05 (1600×). Медијана преко 4 seed-а: 1100×. Претрага по ротацији не
доноси ништа (ротацију механизам постиже сам) и не уводи се.

Инваријантност не чини фитнес попустљивијим него ужим: савршена елипса померена за (2,−1)
пада са 4.623 на 0, али круг радијуса 1 на правом месту добија 0.2155 под сва три режима.

Цена коју треба знати: под пуном скалном инваријантношћу механизам испадне гломазнији од
криве коју црта (највећа полуга / полупречник путање = 6.73, наспрам 1.06 код контроле).
Отуда одлука о компактности испод.

**ОДЛУКА — градирана казна се НЕ уводи.** Остаје равна `PENALTY = 1e9` за сваку невалидну
јединку, без обзира колико је обртаја прешла. Разлог одбијања: „докле је стигао обртај" није
својство механизма него пара (механизам, паркирани угао ручице) — мерено, за исти механизам
вредност варира од 0.00 до 0.78 зависно од почетног офсета. Замена (мера изводљивих углова)
је такође одбијена: градирана казна сама по себи није помогла (0.6×, унутар шума).

**ОДЛУКА — кеш оцене елите унутар истог N.** Јединка која се преноси непромењена и чија је
оцена већ позната на истом N не троши нов позив буџета. **На свакој промени N кеш се
поништава и цела популација се оцењује изнова**, укључујући и елиту — Chamfer са различитих
N није упоредив. Мерено: оцене непромењене елите су бит-идентичне кад се N не промени; у
покретању од 500 генерација то је 9 940 од 50 000 позива, дакле 19.9% буџета.

**ОДЛУКА — подузорковање циљне криве на N.** `curve.resample` се прикључује у `fitness.evaluate`
— за дато N циљна крива се подузоркује на истих N тачака (за N=180 свака 4. тачка). Функција
је постојала од задатка 2 али никад није била прикључена; циљна крива је увек имала свих 720
тачака. KD-дрво се гради једном по нивоу N, не по евалуацији. Ефекат је мали (око 2% на N=90)
и у истом смеру.

**ОДЛУКА — праг угла преноса 10°.** `Config.min_transmission_angle_deg` иде са 5.0 на 10.0.
Ревизија после анализе расподеле углова; следећи разуман корак је 20°. Мерено колико праг
стеже (удео тополошки валидних које заврше пун обртај): 5° → 80.7%, 10° → 73.6%, 20° → 56.8%,
40° → 14.8%. Литературних 40° за четворополужја би побило 85% популације.

**ОДЛУКА — компактност улази само у лог.** `GenerationRecord` добија поље са односом
највећа полуга / полупречник путање најбоље јединке. НЕ улази у оцену док се не види
расподела кроз неколико покретања. Chamfer остаје једина мера квалитета поклапања.

**УПОРЕДИВОСТ:** покретања од 02.09. нису упоредива ни са једним ранијим логом — мења се и
симулатор и фитнес.
