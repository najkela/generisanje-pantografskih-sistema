# Генерисање пантографских механизама за задату криву

Програм који за задату затворену криву тражи раван механизам са полугама чија спрежна
тачка ту криву исцртава. Претражују се заједно **топологија** (који је зглоб окачен о које)
и **геометрија** (положаји зглобова и дужине полуга), два методa:

- **монолитни генетски алгоритам** — топологија и геометрија се мењају у истом кораку;
- **двонивовски метод** — спољашњи генетски алгоритам над топологијама, унутрашњи ЦМА-ЕС
  над геометријом сваке топологије.

Ова грана садржи **само оно што треба да се резултати из рада понове**. Пун ток рада —
закључане одлуке, налази мерења, дневник и радни материјал — стоји на грани `bilevel`.

## Рад

`rad/RAD_v4.pdf` — „Генерисање пантографских механизама двонивовском оптимизацијом: пренос и
проширење информационо-геометријске декомпозиције на графове променљиве величине",
Никола Најић, ментор Бранислав Милојковић, Истраживачка станица Петница.

Логови свих покретања која стоје иза бројева у раду објављени су уз ознаку `ieeestec-2026`
(в. *Releases* на GitHub-у, прилог `logovi_ieeestec_2026.tgz`).

## Шта је где

| | |
|---|---|
| `pantograph/` | пакет: симулатор, геном, валидација, фитнес, оператори, оба метода |
| `run.py` | улазна тачка за једно покретање |
| `tools/` | матрице покретања, цртање кривих грешке, анализе |
| `tests/` | `pytest` свита |
| `data/curves/` | шест циљних кривих нивоа 1, по 720 тачака |
| `rad/` | рад |

## Брзо покретање

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python run.py run --method bilevel --curve data/curves/egg.txt --seed 1 \
    --budget 100000 --rezim poredjenje --fiksno-n 8
```

Тачне команде којима су добијени објављени резултати: **`REPRODUKCIJA.md`**.
